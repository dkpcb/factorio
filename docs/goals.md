# ゲームの目標

## 1. 最終目標

自分たちの工場で宇宙プラットフォームを建造し、太陽系の果てに到達する。到達時にSpace Ageの勝利画面が表示されたら達成とする。

## 2. 惑星間に生産と輸送の仕組みをつくる

ナウヴィスから宇宙に進出し、必要な惑星で現地の資源を使った生産を立ち上げる。各惑星で調達した素材や技術を使い、長距離航行に必要な設備をそろえる。

達成条件は、必要な素材を積んだ宇宙プラットフォームが惑星間を往復し、荷物が受け入れ先の工場で実際に使われること。最後に、補給を終えたプラットフォームで太陽系の果てへ向かう。

## 3. ナウヴィスで役割ごとの工場をつなぐ

採掘、製錬、建設資材、研究を支える生産を順に立ち上げる。近距離はベルトでつなぎ、離れた鉱床や工場には必要に応じて鉄道を使う。建設資材は継続して補充し、新しい生産ラインを増やすたびに手作業で材料を集める手間を減らす。

達成条件は、採掘から製錬、部品生産まで材料が流れ、得られた資材で工場の拡張と宇宙進出に必要な設備を用意できること。

## 4. 新マップで最初に達成すること

鉄・銅の原料になる鉱床、石炭、水を調べ、最初の製錬設備を置ける場所を決める。まず片方の金属で採掘・加工・製錬をつなぎ、次にもう片方を立ち上げる。具体的な設備とレシピは、AngelBob環境のゲーム内で確認した値を使う。

達成条件は、鉄板と銅板の両方が出力箱に届き、燃料と原料が供給されている間は手で鉱石を移さず生産が続くこと。生産が止まった場合は、どの工程で止まったかを確認する。

## AIとの進め方

プレイヤーが次の達成条件と建設方針を決める。ChatGPTは生産の優先順位や物流を検討し、Claude Codeはマップ上の資源と設備を調べて配置案を出す。序盤はプレイヤーが建て、建設ロボットの導入後は、承認した配置をゴーストとして置いて施工する。
